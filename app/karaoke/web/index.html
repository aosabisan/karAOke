Working on

1. Connect to VTube Pro

  1. In VTube Pro open the Track tab, find External tracking and switch on VTube Studio API (plugins).
  2. Press Connect here, then press Allow next to "Aosabi Karaoke" in that same list. You only do this once.
  3. In the same place, set Drive the avatar from to VTube Studio API plugins. While no song plays, your camera and microphone drive the avatar as usual.

While the mouth follows a song, the plugin also blinks for you, and your brows rest. Your head and body still follow your camera.

2. The tools that do the heavy work

These are free tools made by other people. They are not part of Aosabi Karaoke: you install each one yourself with its button, from its official source, into its own folder. Install them when you are not live; each is a few gigabytes.

The installer tool "uv" was not found. Close Aosabi Karaoke and start it again with its start file, which offers to get it.

3. Voice models

Put your voice models in this folder, then press Refresh:

  • RVC: the .pth file, and its .index file next to it if you have one.
  • so-vits-svc: a folder holding G_....pth and config.json.
Use another voice tool (any format)

Type the command line of your tool. These words are filled in for you: {input} {output} {model} {index} {config} {pitch}. Leave empty to use the tools above.

Only use a voice you have the right to use: your own, or one you have the person's permission for.
